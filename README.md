# daily

Checklist diário de tarefas recorrentes, organizadas por período. Os checks são reiniciados automaticamente todo dia.

## Development

```sh
yarn
yarn dev
```

## Scripts

- `yarn dev` — servidor de desenvolvimento
- `yarn build` — build de produção
- `yarn preview` — preview do build
- `yarn lint` — lint
- `yarn format` — formatar com Prettier

## Stack

- Vite
- TanStack Router
- TypeScript
- React
- Tailwind CSS
- PWA (service worker)
